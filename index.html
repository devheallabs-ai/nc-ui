How It Works

Three steps, no build pipeline

Write plain English
→
NC UI compiles
→
Ship static files

1 · Write

Describe the page in readable commands. No angle brackets, no class names, no semicolons.

2 · Compile

The compiler turns that source into production-ready HTML, CSS and JavaScript.

3 · Ship

Deploy anywhere that serves static files — any static host or your own server. No runtime needed.

NC-Native

NC UI is not a JavaScript framework

This is a comparison of approaches, not of named products. Mainstream JavaScript frameworks bring a large ecosystem and capabilities NC UI does not attempt to match. NC UI is the alternative when you want plain-English authoring, static output and a smaller deployment surface.

Typical JavaScript stack

Large ecosystem, more moving parts

A framework plus a package manager and build tooling gives you a deep component ecosystem, but adds lockfiles, dependency churn, bundler configuration and a build step to maintain around what may be a simple site.

NC UI

Compiles, then gets out of the way

Write in NC UI, build through NC, ship plain HTML, CSS and JavaScript. No manifest or lockfile is required to deploy the compiler's output, and there is no runtime on the server.

With NC AI

Generate a front end from a description Beta

NC UI works with NC AI. The current v1 binary is validated to generate an app.ncui front end together with the backend, tests, documentation and a compiled bundle from a single English prompt.

nc ai create "multi-tenant operations dashboard with role based
        access, analytics, alert center, approvals and dark theme"

# generates
app.ncui        # NC UI front end
service.nc      # backend
test_app.nc     # tests
README.md       # docs
dist/app.html   # compiled bundle

Contract validation

Generated NC UI is checked for structural validity and repaired before it is written out.

Runs locally

Generation uses the local NC AI engine, so no source leaves your machine to produce a page.

Get Started

Up and running in seconds

NC UI ships inside the NC binary. Install NC, then build your first page.

# install NC (NC UI is included)
curl -fsSL https://nc.devheallabs.in/install.sh | sh

# check it
nc version

# build your first page
nc ui build my-site.ncui
Prefer to try before installing? Run NC UI in the NC UI playground — no installation required.
